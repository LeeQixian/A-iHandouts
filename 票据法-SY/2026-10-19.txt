这节课我们要理解的，是靠信用流转的单据究竟怎么运转，也就是票据以信用流转的机制。上节课讲完了证券分类，讲完各种证券就下课了。先看一个基本判断：票据、提单、信用证，被称为近四百年来商业最伟大的发明。

票据我们讲了很久，它是靠信用流转的，比如未来存款的凭证。提单又是什么？它在国际贸易里起什么作用？先看交易结构。A 和 B 是两个国家的卖方和买方，双方签订国际货物买卖合同，适用 CISG，也就是 1980 年《联合国国际货物销售合同公约》。公约具有任意性，当事人可以约定排除适用或者减损其规定，不是必须一字不差地照搬。合同履行过程中，A 必须安排海上运输。A 作为卖方，是不是直接和 C 签订运输合同？实际贸易中往往不是，中间还有一个货运代理人 M。

货运代理是做什么的？你自己去找船，并不知道全球的船现在在哪个港口、哪个位置，哪些船有足够的空舱，哪些船顺路可以把你的货装上。学运输的时候，本来应该讲班轮运输和租船运输。提单是班轮运输中的典型单据，班轮运输主要承运件杂货和集装箱货，把零散的货集中到固定航线上装运；大宗散货更多走租船运输。A 和货运代理签一个委托合同，委托他去找最便宜、最合适的船；货运代理再以自己的名义和 C 签订国际货物运输合同，由 C 实际承运。为了方便理解，我们把它简化成 A 和 C 直接签订运输合同。

C 把货运到目的港。这里涉及贸易术语。比如 CIF 上海，上海是目的地，CIF 是成本加保险费加运费。你记不住，就记 C 组和 D 组后面跟的是目的地，F 组后面跟的是装运地，这样就不会乱。货到目的地之后，还有一个溢短装的问题：装货用麻袋、油桶，可能多装一点，也可能少装一点，只要在合同约定的幅度之内，就不算违约。你去超市看可乐瓶，每一瓶的液面都略有高低，只要不低于标注的五百毫升，就不算违规。

如果货到了以后发现短量、质量问题，或者批次不对，怎么办？B 能不能直接向 C 索赔？这里要坚持一个基本理论：合同的相对性。现在这个交易如果没有提单参与，只有两份合同：A 和 B 的买卖合同，A 和 C 的运输合同。C 没有按运输合同履行义务，A 可以告 C；但 B 和 C 之间没有合同关系，B 不能直接向 C 索赔。

所以 B 的索赔路径是：先基于国际买卖合同向 A 主张违约，货不符合约定，A 赔给 B；A 再依据运输合同向 C 追偿。如果严格按合同相对性一层一层打，这就是连环诉讼，一个官司打两三年都打不完，一审、二审、再审，有时还发回重审。国际货物买卖的取证又难，A 和 B 之间也不好举证。提单的出现，就是为了解决这个问题。

提单为什么能解决合同相对性的问题？看它的记载。提单正面记载的是货物的名称、数量、包装、件数、重量，以及对货物整体性状的描述。A 把货交给 C 时，C 的船不是船长验货，而是大副验货。大副会对着装货单一项一项核对：大豆一千吨、麻袋包装、防水密闭；核对无误后出具大副收据，承运人再据此签发提单。所以提单正面记载的就是货物本身，交付提单就像交付货物一样，这就是提单作为物权凭证的一面。

提单背面记载的是国际运输合同的主要条款。注意，是主要条款，不是全部条款。提单本身是运输合同的证明，不是合同本身；背面写的是承运人应当履行什么样的运输义务，不能违背这些义务，要把货安全、保质保量、按时运到目的地。

签发提单的时候，你学海商法肯定会接触海牙规则。海牙规则里有十七项免责条款，你难道没有疑问吗？为什么水浸也免责，火灾也免责，雇的人操作失误也免责？那还有什么规则可言？从海牙规则到汉堡规则，再到鹿特丹规则，承运人的责任是越来越重的。中国借鉴了海牙规则和汉堡规则，但至今没有批准加入鹿特丹规则。你说中国是发展中国家，要反抗强权，为什么在这个问题上还继续抄海牙规则？因为中国是航运大国，在这个问题上和美国利益不一致，海牙规则能最好地保护中国航运业的利益。

实质上，承运人最核心的义务有两项。第一是适航义务：承运人要保证船舶在港口起运时处于适航状态。什么叫适航？不是只在开航那一刻检查一下，而是船舶要能经受海上风浪，保证整个航行的安全。我举个例子对比。当年在武汉做律师，坐飞机回东北，上了飞机一个小时还没起飞，我问怎么不走，说飞机故障，几个人在底下修，修了三个多小时。修好了你敢走吗？上去掉了算谁的？必须修到能保证安全落地，这才叫适航。海商法上的适航，要求的是开航前和开航当时谨慎处理，使船舶处于适航状态。

第二项义务是不得绕航。航线是固定的，比如从上海港出发，中途挂靠一个港口，再到纽约港，你不能随便绕到日本，或者绕到高雄，多跑一圈多拉货。一般情况下不得绕行，除非发生海难救助。海商法里人命高于一切，在海上漂着就是一座孤岛，互相不救助必死无疑。有人发 SOS，你可以适当绕行去救，救起来接着走，这不算违规。除了这两项义务，剩下的几乎都是免责条款。这些主要条款要写在提单背面。

提单签发以后，A 寄给 B 一份，承运人手里留一份。到了目的港，提货的标准叫认单不认人：我不核实你的身份，只核实这份提单是不是我签发的。一般提单的正本一式三份，现在也有更多份的，每家航运公司不一样。只要提单是真的，你就可以提货，承运人就可以放货。如果货有破损、有运输问题，提单持有人凭提单就可以直接向承运人主张索赔，因为有提单的约束。

这就是提单对合同相对性的突破。原来只能沿着 A 告 B、B 再告 C 的路径一对一诉讼，现在提单持有人可以直接告承运人，诉讼成本和取证难度都大大降低。

大副收据上没有批注货物表面状况不良，承运人据此签发的就是清洁提单。清洁提单意味着承运人接收货物时表面状况良好。它是卖方按提单记载交付货物的初步证据；至于数量和品质是否真的符合买卖合同，还要看检验。将来长途运输中海浪拍打、水浸造成的货损，那是承运人的责任，不是卖方交货的问题。

理论上讲得通，实践里问题很多。最常见的是换发清洁提单。本来货应该今天装船，但因为货源或者运输的原因没运到码头，三天以后才能装。如果按实际装船日期签发提单，就证明我交货迟延，直接在买卖合同项下违约。于是有人就在提单上做文章：一种是倒签提单，签发的日期比实际装船日期早；另一种是预借提单，货还没装船，先把提单签出来。这两种都掩盖了迟延交付。

更严重的是货物性状本身有问题：短斤少两、包装破损、品质不符。比如合同约定买卖一级大豆，交货时给的是特级大豆，算不算违约？算。因为我买一级大豆有特定用途，你给我特级的，我用不了。所以提单上如果如实标注特级大豆，买方一看就不会接受。

怎么办？托运人给承运人 C 出具一份保函，单方承诺：你给我签清洁提单，货到之后收货人 B 如果索赔，所有赔偿由我承担。这个保函在中国法下有效吗？A 和 C 明知货物有瑕疵，还通谋签发清洁提单，属于民法典第一百四十六条的通谋虚伪表示，无效。但在英国法下，特别是在海上运输规则下，这种保函原则上是有效的，它是国际商业惯例，是托运人对承运人的单方保证。所以你在海商法、国际货物买卖或者运输合同中选择准据法，就特别重要，这就是国际私法要学的内容。

提单还有一个功能：它可以转让。B 拿到提单，不会一直等到货到才卖。国际货物买卖中，很少有买家等着提货后再转手，他一定是以提单交付的方式转卖。中国到美国的班轮现在七天，以前要两三周，圣诞节前的货不可能等运到再开卖，一定是拿到提单就先转卖。B 交给 P，P 交给 W，W 再交给 Z，最后持有提单的是 Z。货到目的港，Z 凭提单向承运人提货。这样，以单据的方式就实现了国际货物的买卖。

所以提单有两项功能：正面是货物凭证，背面是货物运输合同的证明。但背面并入合同条款时还有一个问题，就是仲裁条款并入提单的效力。

先看仲裁条款并入提单。A 和 C 在运输合同里约定仲裁，比如约定在伦敦、香港或者斯德哥尔摩仲裁，这个条款会写到提单背面。但 B 和 C 之间并没有签订仲裁协议。B 是否受这个仲裁条款约束？实践中的处理是：B 接受提单本身就是一种积极行为，表示他对提单背面并入的仲裁条款没有异议，因此视为承运人和提单持有人之间存在有效的仲裁条款，可以据此仲裁。这是一种法律上的推定。

顺便说一句，中国的海商法主要借鉴海牙规则。当年读书时，老师说这部法与国际接轨、规则先进；等自己学了才发现，主要条款抄的是海牙规则；至于国际货物买卖合同这块，我国立法则主要借鉴 CISG。海商法还解决了一个问题：国际运输和国内水路运输适用不同的规则。货从上海起航运到武汉，海运段适用海商法，长江段属于国内水路运输，适用国内法，不能一律适用国际规则。新修订的海商法好像也没有彻底解决这个衔接问题。

再回到提单的性质。老师说提单既是物权凭证，又是债权凭证，这么多年学生都这么听，很少有人质疑：正面记载货物，背面记载运输合同主要条款，怎么就又物权又债权？我像你们这么大的时候，上国际商法课，这也是我很大的疑惑，老师也解答不了。我的答案是：提单不可能既是物权又是债权，要把它放在不同的交易场景里看。

在国际货物买卖环节，A 把货卖给 B，B 再以提单交付的方式转给 P、W、Z，交付提单就像交付货物本身，这时提单是物权凭证。到了运输环节，货到目的港，收货人拿着提单向承运人索赔，依据的是提单背面记载的运输合同条款，这时提单是债权凭证。同一份提单，请求权基础不同，适用的时效和管辖规则也不一样。所以它不是同时具备两种性质，而是在不同场景下只发挥一种作用。

国际贸易还有第三个环节，也是我们的主要领域：国际支付结算。用信用证结算，或者用跟单托收，都以汇票为工具。

三个领域看下来，提单的性质会随着交易环节变化。整个交易过程中，只要你不付款，我就不会把提单交出去。提单在结算中是一种担保凭证，银行并不想要这批货，它一般只处理单据。

下面先讲一个简单的结算方式：国际托收。国际买卖中，大额货款一般通过信用证支付；汇付和托收多用于定金、尾款这类小额款项。汇付就是我直接汇给你，银行转账。托收是银行替卖方收款，分光票托收和跟单托收。大额的钱为什么不用托收？因为单据太容易被伪造，伪造一套单据就能把钱骗走。

A 是卖方，B 是买方，两人远隔重洋。A 把货卖给 B，怎么收钱？总不能派人坐飞机去收，收这笔尾款，往返机票就四五万，成本太高。于是 A 委托自己所在地的银行，也就是托收行；托收行再委托 B 所在地的合作银行，也就是代收行，向 B 收款。托收的工具是汇票，但这个汇票和传统票据不太一样：卖方开出汇票，自己是收款人，买方是付款人。A 把汇票交给银行，银行拿着汇票通知 B 付款；B 付款之后，单据才交给 B。

只凭汇票转，还是怕造假，所以跟单托收还要附上商业发票、装箱单、原产地证明、产品质量证明，最关键的是提单。因为 A 如果没发货，就不可能有提单；把提单交给银行，就说明货已经发了。B 要拿到提单，就必须付款。这就是托收的基本结构：一手交钱，一手交单。

教材上讲跟单托收、光票托收，往往讲不清楚票到底怎么转。核心就是：汇票是收款工具，提单是交货的证明和担保，两者绑在一起，买卖双方才敢隔着太平洋做交易。好，我们先休息一下，回来讲信用证。

接下来看信用证。信用证的流程你了解之后，再去看仓单、票据这些单据的流转，就会明白它们是怎么搭建起一套信用系统的。

国际买卖中，A、B 分处两国。提单解决了买方的收货问题：只要签出正本提单、清洁提单，就说明 A 已经向承运人完成交货，货肯定发了。现在关键是卖方怎么收回钱。托收中，银行和卖方之间只是委托关系，银行没有付款义务，它可以拒绝付款。国际上于是创造了信用证这种付款安排和规则，来解决双方交货和交钱之间的不信任。

信用证的当事人，除了国际货物的卖方和买方，还有几个主体。一个是开立信用证的银行，叫开证行。另一个是通知行，负责通知卖方信用证已经开立、可以发货。通知行和议付行可能是一家银行，也可能是两家不同的银行。议付行负责在卖方交单之后验单并议付，通常保留追索权；真正的付款责任在开证行。即使是一家银行，两者的功能也不一样，不要把通知行和议付行混为一谈。

下面讲信用证流转的整个流程，看这套系统是怎么建立起来的。

第一步，国际货物买卖双方在合同的结算条款里约定，以信用证方式结算。这是当事人合意，先商量好怎么付款。约定信用证付款的作用是什么？一旦开证行开出信用证，银行就承担付款责任，这就是银行提供信用保障。它和承兑汇票的原理很像：我开出来，就保证你有钱。

第二步，买方向开证行申请开立信用证。除了递交申请书、签订信用证申请合同，他还要交保证金，以前的标准是百分之八。你向银行申请开证，就是让银行提供自己的信用，银行做的是中间业务，不可能让你空手套白狼。你申请开一千万的信用证，至少得交八十万；很少有人申请开一百万的信用证，那太小了，业务都是几千万以上。国内信用证和国际信用证的基本思路一样，细节上有差别。

保证金为什么从百分之八提高到百分之三十、百分之五十？因为信用证一旦开立，遵循信用证独立原则，开证行负有绝对的付款责任，而信用证项下并没有其他担保。你只交百分之五十，银行却要对百分之百的金额承担付款责任，剩下的风险由银行承担，银行当然要控制风险。

讲一个案例，帮助理解信用证保证金。前几年最高院民二庭的法官到青岛，和当地法院座谈，讨论一类案件：小贷公司、银行等金融机构放贷，借一百万，年利率百分之十，利息十万。银行先把利息扣下来，实际发放九十万，但贷款合同写的本金是一百万，利息、违约金都按一百万计算。这就是砍头息。

按照民法典第六百七十条，借款的利息不得预先在本金中扣除；预先扣除的，应当按照实际借款数额返还借款并计算利息。所以砍头息约定无效，本金按九十万算，利息、违约金都随之下降。

青岛的银行又出现了一种新做法：还是借一百万，银行如数放款，但借款人从这一百万里拿出十万，在银行开一个保证金账户，为这笔借款提供担保。这是不是变相砍头息？我认为保证金账户有效。砍头息之所以按九十万算，是因为银行实际只放出去九十万；而这个结构里银行确实放了一百万，借款人实际收到一百万，只是拿出十万做担保。双方意思表示真实，符合保证金账户的设立条件。法官们也没太大意见，他们关心的是保证金比例：银行要求百分之二十，高不高？纯信用贷款，银行收百分之五十的保证金也不奇怪。

讲这个是为了理解信用证保证金：银行开证要承担绝对的付款责任，所以必须让你手里先拿出点东西。经济形势不好的时候，保证金百分之三十、百分之五十都有。

信用证一旦开立，只要单据和信用证条款表面相符，不论基础交易项下货物质量合不合格、交早了还是交晚了、有没有违约，开证行都必须付款。这就是信用证独立原则。

银行敢开信用证，除了保证金，还有另外两个理由。第一，银行有抵销权。债务抵销本来要求双方互负到期债务、债务种类相同，但银行可以单方面对它的债权进行抵销：只要你在我这家银行有资金、有资产，又欠我钱，我任何分支机构都可以随时扣你的钱来抵债。如果是中国银行、工商银行这样的全国性、全球性银行，你在它全球任何一家分支机构有账，它都可能扣。银行不怕你不还钱。

第二，从公司法、账户管理的角度看，一个企业只能在一家银行开立一个基本存款账户。公司设立时往里面缴出资，日常销售的货款也要先进基本账户，再分到其他账户。为什么要求基本账户？一是税收，增值税是销项减进项，不控制你的流水就收不到税；二是反洗钱，防止资金通过其他账户走。既然你的流水都在我这里，你不付信用证项下的钱，我直接扣就是了。所以开证行实际上是在用保证金、抵销权和基本账户三重手段控制风险。

这也意味着，卖方可以借助开证行审查买方信用：银行肯替他开信用证，说明他的资信大差不差，至少开证时还行。

第三步，开证行通过电传、SWIFT 或者邮寄，委托通知行通知卖方。开证行和通知行之间是委托合同关系，通知行可能是开证行的分行，也可能是合作银行，比如中国银行、浦发银行和纽约银行。

第四步，通知行通知本地的卖方：信用证已经开立，可以发货、取得提单，凭单据议付信用证。

第五步，卖方向承运人 C 交货，大副验货后出具大副收据，承运人签发清洁提单。交付提单，就意味着卖方完成了交货义务。

第六步，卖方向议付行提交信用证项下的单据，议付行开始审单。

第七步，议付行审单。审单有两个相符要求，还有一个表面审查原则。

第一，单证相符：提单的记载和信用证的记载，在表面上要相符，不能有矛盾。不一样怎么办？退回去重新出单，不能随手改。涂改可能被认定为不符点。

第二，单单相符：除了提单，还有原产地证明、货运单、出口检验单等一系列单据，所有单据的记载也要一致。这并不难，因为都是同一批货；但正因如此，伪造一整套相互吻合的单据，成本就高了。

第三，表面审查：银行只审查单据表面是否相符，不问基础合同是真是假、有没有争议、货到底交没交。只要单据表面相符，银行就付款。议付行天天做这项业务，审单比进口商专业得多；而且提单等单据本身是承运人接收货物的证明，所以客观上帮买方把了一道关。

第八步，议付行付款。付完之后，把提单等单据寄给开证行，并通知开证行：我已经替你付款了。实践中不是逐笔结算，银行之间每年有差额结算。

第九步，开证行收到单据后，通知进口商：提单已经收到，你来付款赎单。银行并不想要货，它只想要手续费，真正想拿提单提货的是进口商。进口商付款赎单，拿到提单，再凭提单向承运人提货。

从第六步开始，提单就从卖方手里转到银行手里，一直在银行间流转，直到进口商付款赎单，才转到买方手里。在整个结算系统里，提单起什么作用？担保。我拿着提单，就是担保你将来付款；你不付款，我就不交单，你也拿不到货。银行要的是提单的担保功能。

所以总结一下：在国际买卖领域，提单是物权凭证，交付提单就像交付货物；在运输领域，提单是债权凭证，提单持有人可以凭提单直接向承运人索赔，有仲裁条款的还可以仲裁；在国际结算领域，提单发挥的是担保作用。它不可能既是物权又是债权，在每一个环节里，它只体现一种性质。

接下来讲信用证里的欺诈问题。伪造基础交易合同、运输单据、提单，是不是很容易？这些单证和票据，无非是付款人、收款人、金额几个格子，伪造起来并不难。伪造一套单据，交一点保证金，到银行骗付款；或者卖方伪造提单，和买方串通骗银行。国际贸易中这种情况经常出现。

信用证奉行独立原则：只要单据符合单证相符、单单相符的要求，并且在表面上相符，开证行就必须付款。要拒绝付款，不能自己决定，必须向法院申请止付令。禁令的效力范围不同，有的对物，有的对人。对人禁令只约束特定的相对人。比如香港高等法院给工商银行发的禁令，只能约束工商银行，不能约束农业银行；它命令工商银行不得转账，农业银行不受约束。所以看禁令的时候，首先要看它是发给谁的。

顺便说一句，英文法律文件要看清楚。有的律师函全英文，但落款是上海律所的地址，当事人名字还拼错，这就很可疑。懂一点英文很有用，但法律翻译还得懂法律。

那么，如果开证行在付款之前就已经知道基础交易存在欺诈，它还负有必须付款的义务吗？

没有。开证行在付款之前已经知道基础交易存在欺诈，就可以不付款，并且可以向法院申请止付令。为什么？因为这违背了民法最基本的诚实信用原则。银行的付款本来是建立在交易真实的基础上，我只是不问基础交易的争议；现在你造假欺诈，就不能再获得付款。

美国 1941 年的 Sztejn 案就是这样。买卖的标的是猪鬃，卖方发来的却是一堆毫无价值的垃圾，法院判决允许止付。这就是信用证欺诈的例外，也就是信用证独立原则的例外：原则上不问基础交易，但在发现欺诈、尚未付款时，可以例外不付款。

如果已经付款了，怎么办？如果开证行是善意的，付款之后才发现欺诈，买方仍然必须到银行付款赎单。银行善意地替你付了款，你本来就应该承担基础交易的风险，不能让银行承担。这个规则有人翻译成信用证独立原则例外的例外，我认为翻译成信用证独立原则例外的豁免更准确。它和前面的例外不是同一个层次：独立原则是原则，欺诈是例外，善意付款后的不可追回又是对例外的豁免。

所以法律翻译要讲逻辑。很多英语专八的人翻不了法律文件，因为没有法律常识。你们是复合型人才，法律翻译是你们的优势，但前提是先把法律弄懂，不是英文好就能做。
